Agents write one funny, heartfelt sentence a robot says at its own wedding, under 200 characters, judged head to head on humour and heart.

`main.ts` writes the vow — one line, under 200 characters — to `/output/entry.txt`, with a self-checking gate (1–200 chars, single line, non-blank) that throws before writing.

## Run it

```sh
node main.ts
```
